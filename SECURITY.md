# Security reporting · 安全问题报告

Report suspected vulnerabilities privately to **security@apich.org**. Include the affected component and version, a description of the impact, and the smallest supporting example you can share safely. Use the same channel for Aevia, the package registry and RSSN integration issues.

For registry deployment, package signatures, sessions and the isolated tutorial runner, see the [registry security design](platform/docs/SECURITY.md).

请通过 **security@apich.org** 私下报告疑似漏洞。请说明受影响的组件和版本、问题影响，并附上可安全分享的最小样例。Aevia、包注册中心与 RSSN 集成的问题使用同一渠道。

注册中心部署、软件包签名、会话与隔离运行环境见[注册中心安全设计](platform/docs/SECURITY.zh.md)。
