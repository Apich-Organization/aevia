# 验证科学计算结果

量纲检查能发现不相容的方程。测试验证方程的实际含义、数值稳定性和边界行为。尽量用可独立推导的结果构造测试。

## 测试一个模型

此函数返回圆面积。第一个测试使用半径为零的精确结果，第二个测试验证半径翻倍时的倍率关系。主程序供探索使用，`aevia test` 执行测试声明。

```aevia,run
fn circle(radius: Float[Length]): Float[Length^2] =
    3.141592653589793 * radius^2

test "zero radius has zero area" = circle(0.0 m) == 0.0 m^2

test "double radius gives four times the area" =
    abs(circle(2.0 m) - 4 * circle(1.0 m)) < 0.000001 m^2

fn main(): IO Unit =
    println(circle(3.0 m))
```

将程序保存为 `circle.aev`，运行 `aevia test circle.aev`。然后把平方替换成量纲正确但物理上错误的公式，如 `radius * 1.0 m`。再次运行，看看哪个断言发现了错误。

## 添加可编译的文档示例

`##` 文档注释可以包含用围栏标注的 Aevia 示例。`aevia test --doc` 检查其中的代码。每个示例是独立的合成模块，因此需要显式声明必要的绑定或添加导入。用于展示特定量纲错误时，可在首行写 `compile_fail E0401`。验证数值时使用可执行测试声明。

## 使用一致的误差尺度

根据问题选取容差，使用与残差相同的量纲。远离零时可用相对误差，接近零时选择有意义的绝对尺度。对有多个分支的算法，为每个分支添加代表性用例，并在边界两侧各取一个值。并行运算可分别用一个工作线程与多个工作线程验证输出。

## 动手检验

数值回归用独立获得的预期结果，例如手工推导或精确解。至少验证一个边界和一个在表示变化后仍应成立的关系。带量纲的容差同时说明允许误差及其单位。
