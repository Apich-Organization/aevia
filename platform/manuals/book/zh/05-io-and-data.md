# IO、数据与错误

把计算保留在纯函数内，由 `main` 读取外部输入、选择错误处理方式并报告结果。`IO a` 表示产生 `a` 的动作。在 `do` 块内，用 `<-` 绑定执行动作后的结果，用 `let` 绑定普通表达式。

## 从命令行传递参数

将下面的程序保存为 `arguments.aev`，运行 `aevia run arguments.aev -- station-17 evening`。在浏览器版中可以观察空参数的情况。

```aevia,run
fn main(): IO Unit = do
    let supplied = args()
    println(length(supplied))
    println(supplied)
```

`--` 分隔工具选项与程序参数。在这一边界把字符串解析成模型参数，让后面的程序直接接收数字和物理量。

## 给数据导入定义清楚的边界

在本地分析 CSV 或 JSON 时，先查阅 [Data](/stdlib/Data?lang=zh) 模块文档。用模式说明预期的列、类型和单位，并分别处理文件无法读取、字段模式不匹配和无效数据的情况。批量运行前，先检查几行数据并使用已知结果的小样本。前导零有意义的编号和很长的标识符适合保留为文本。

本地文件动作用 `fs` 能力。用 `aevia --caps fs run path/to/program.aev` 试运行仅授予文件能力的程序。多个能力名用逗号分隔。`with_cap` 缩小一个动作作用域的权限。执行不可信程序时使用进程沙箱。

## 分开计算结果与输出方式

让模型层返回结构化结果，例如 `{ value = estimate, samples = n }`。可以在 `main` 中用 `println` 输出，也可以用标准库生成数据集。批量计算时，保留每个失败结果的输入标识。能够指明无效文件或列的诊断比笼统的失败提示更便于处理。

练习是为包含站名和读数的记录写一个纯验证函数。接入文件之前先传入三个具体例子。测试声明见[验证科学计算结果](11-testing.md)。
