# 张量与线性代数

张量的秩是轴的数量，形状给出各轴的长度。`Tensor<2, Float>` 指定秩，`Tensor<[2,3], Float>` 还指定各轴长度。如果轴在数学模型中有明确含义，可以在函数边界标注固定形状。

## 应用线性模型

下列矩阵的每一行给两个独立读数分配权重。把运算写成矩阵与向量的乘积，检查器就能联系共同的轴和物理量纲。

```aevia,run
fn predict(weights: Tensor<[2,2], Float>, inputs: Tensor<[2], Float[Length]>): Tensor<[2], Float[Length]> =
    weights @ inputs

fn main(): IO Unit = do
    let weights = [[0.75, 0.25], [0.4, 0.6]]
    let values = predict(weights, [2.0 m, 6.0 m])
    println(shape(values))
    println(values)
    println(mean(values))
```

两个预测值分别为 3 m 和 4.4 m。改变向量长度，再检查程序。共同的轴属于运算的约定。张量之间的 `*` 表示逐元素乘法，线性代数乘积使用 `@`。

## 按结构选择求解器

对稠密线性系统，将系数矩阵和右端项传给 `linsolve`。检查返回结果并计算残差 `A @ x - b`。精确运算可比较相等。浮点输入应比较范数与同量纲的容差。较小的残差本身无法证明系统的条件良好。

图的关联矩阵和微分算子的离散矩阵通常只有少量非零项，适合稀疏表示。[稀疏模块](/stdlib/LinearAlgebra.Sparse?lang=zh) 区分不同布局并提供显式转换。放大网格前，先在小规模问题上用稠密算法进行对照。

## 动手检验

标注每个轴的含义和相关单位。先手算一行，再比较整个结果。保持读数并交换矩阵两列，解释结果变化。形状检查保证长度，手算用例核对每列对应的仪器。 [求解并校验残差](20-solve-with-a-residual.md)
