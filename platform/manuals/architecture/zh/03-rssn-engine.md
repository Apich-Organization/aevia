# RSSN 图、重写规则与数值后端

RSSN 用等价图联系一个表达式的不同符号形式。数值算法也以 Rust 内核形式存在，宿主可以直接调用而无需构造符号项。

## 会话与约简

会话拥有项存储、规则与单位。哈希驻留让同一存储中相等的节点共享标识。重写合并等价类、更新分析事实，并重建受影响的父节点关系。提取器遍历请求项可达的等价类，并按当前代价模型选择结果。信息充分时，操作携带图所推导的形状、类别与量纲证据。

`Session::compute` 从已安装模板准备私有计算图，执行约简，再导入答案。`compute_all` 在入口读取本批使用的缓存，随后由工作线程在独立图上准备并执行计算，批大小由当前 Rayon 池决定。会话所属线程按输入顺序导回答案。缓存标识包含请求和会影响结果的配置。注册环境的改变使依赖旧环境的缓存失效。

## 调度规则与内核

规则按层组织。调度器根据算子选择相关的重写批次与数值内核。连续规则可并行搜索被冻结的图，然后按稳定顺序应用匹配。增量搜索通过变更轮次避开与修改无关的赋值。选择两阶段执行的内核提取普通数据，独立完成计算，然后按节点顺序提交。

预算和取消各有用途。预算限制请求可用的工作量，取消令牌让调用方能够停止支持取消的进行中操作。中途取消的结果不能作为完成的计算复用。数值运算通常另有步数、区间数、容差或回调次数等限制。

## 数值执行

类型化内核涵盖稠密与稀疏代数、积分、ODE/SDE/PDE、统计、FFT 和仿真。直接算法负责验证输入并定义结果类型，项规则和类型化 ABI 适配器在边界转换参数和结果。

`Rssn_Numeric.coherence` 计算单边 Welch 相干度。`Rssn_Numeric.wavelet_packet` 同时分解小波变换的低频和高频分支，以等宽矩阵返回叶子频带。`Rssn_Numeric.inverse_wavelet_packet` 从该矩阵重建输入。带类型的 `num_signal_*` 算子通过原生数值 ABI 提供解析信号、Hilbert 变换、幅度包络和局部 FFT。

CPU 并行按当前 Rayon 池和工作量阈值调度。全局池自动探测可用 CPU，也可用 `RAYON_NUM_THREADS` 配置。RSSN 在 Aevia 的并行语言工作线程中使用外层线程池。`kernels::reuse` 在保留上限内共享不可变计算计划，并借出独占的临时缓冲区。FFT 按长度和方向复用计划，在运行时选择 CPU 指令。

编译求值可以使用指令带，支持标量、批量、自动微分和区间执行。LIR 提供有类型的寄存器、分支、调用和回退出口。启用 JIT 特性时，Cranelift 编译符合条件的工作。可选设备后端提供显式缓冲区与启动模型。要求复现的数值实验应记录精度、归约顺序和所选后端。

## Arena 中的两种身份

`NodeId` 标记具体项。结构哈希表按算子、载荷与有序的具体子节点驻留项，重复子树共享存储。`ClassId` 标记等价类。并查集确定规范代表，成员环将两个类并接且保留原节点。合流表用已规范化的子类比较父节点，使用链记录合并影响的父项。重建可以继续发现合流关系，既有项句柄仍然有效。

```text
构造项 → 结构驻留 → 具体 NodeId
                       ↓
重写或内核推出等价 → 合并类 → 待重建的父项使用链
                         ↑                  ↓
                     父项合流 ← 重新规范化子类
                         ↓
                   按代价抽取 → 具体结果
```

分析事实随等价类传播。数值见证、排序、量纲和结构事实向守卫及内核提供证据。守卫规定恒等式生效的域。证据不足时，请求可以保留为符号式。数值定义域错误通过受检查的调用边界报告。

## 调度阶段如何控制工作量

调度器从请求根出发，只查询可达类。规约层优先推进微分等算子，再做归一化。树窗口在局部表达式上执行破坏性化简。探索性恒等式可能扩张图，因此应用节点预算和规则退避。当得到闭式或数值见证时，目标条件可提前结束请求。匹配阶段可以并行读取冻结视图，合并结果、类并集和合流重建由图所属线程按稳定顺序完成。

具体项与等价类的生命周期不同。抽取阶段在可达类中比较候选代价并返回具体代表。不动点描述当前规则集和预算可达到的结果。数值请求的报告分别给出结果、终止原因和可用的误差或诊断信息。

## 符号、原生数值和编译路径

| 边界 | 状态与用途 |
|---|---|
| `src/api/mod.rs`、`src/graph/schedule.rs` | 会话配置、独立计算图、重写预算与结果 |
| `src/graph/store.rs`、`facts.rs`、`extract.rs` | 结构和合流存储、分析事实及代表项抽取 |
| `src/rules` | 符号定义、带守卫的恒等式及数值适配器 |
| `src/kernels`、`src/sim` | 直接算法的规模、容差、定义域检查和结果类型 |
| `src/backend/tape`、`lir.rs`、`lir_jit.rs`、`device` | 标量及批量带、寄存器代码、机器码入口和启动缓冲区 |

自适应积分器拥有自己的状态缓冲区和终止规则，可由图算子经类型化适配器调用。编译的标量代码使用寄存器和缓冲区，支持的精度与执行资源由具体后端决定。复现实验时应同时记录后端功能和权限。 [调用与所有权契约](04-abi-and-persistence.md)
