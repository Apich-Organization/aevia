# 包注册表与文档

Axum 服务器向客户端提供 API，向浏览器提供 HTML。PostgreSQL 保存目录、身份和追加式透明记录。独立归档存储按版本和校验和保留包内容。Leptos 依据视图模型生成 HTML，语言文档工具将公开注释转换为 Markdown 和经过清理的 HTML。

## 发布版本

客户端压缩包，并以包名、版本和校验和请求挑战声明，对服务器返回的原文签名。服务器一次性消费一枚短时 nonce，以发布者已登记的密钥验证声明及签名，再确认包元数据与归档相符。授权限定在指定所有者的包范围内。OpenPGP 与受支持 SSH 签名使用同一规范化声明格式。

目录行、索引和透明日志记录描述同一个版本。下载方可用发布的校验和检查内容标识。撤回改变版本状态，使用者仍可验证已经解析到的版本。生成文档前，系统限制并验证归档结构。

## 在同一站点提供多种来源

包页面源自归档源码及存储的构建结果。规范与手册源自挂载的双语源码。标准库参考由 CLI 的文档集合渲染，模块与公开声明来自用户导入的同一组嵌入源码。算子实现文档归入内核目录。

站点成功重新装入文档后切换到新的快照。进行中的请求可继续读取旧快照。独立 HTML 下载版合并同一套章节，不带执行控件。

## 运行简短教程程序

配置了执行服务时，网页服务将示例交给受限的私有执行服务。工作进程在独立 Podman 容器中调用 Aevia，采用只读镜像、关闭网络，并限制 CPU、内存、进程数量和最长运行时间。返回标准输出、标准错误及退出状态。执行服务不接收生产数据库凭据。未配置服务时仍可以提供交互版页面与静态版文档。
