# 语言流水线与工具

命令行与编辑器经过同一个前端，因而对源码含义有相同的判断。

```text
源码与包上下文
  → 解析导入 → 记号及布局 → AST
  → 名字、类型、量纲与形状检查 → CheckedModule
  → Core IR → 求值器 → 值、IO 动作及诊断
```

## 前端保留的信息

词法分析记录源码区间，语法分析把布局转为模块和表达式结构。名称、量纲和重载的含义依赖导入环境，因此在检查器中解析。模块驱动按依赖后序访问各文件，即使多个包包含同名模块也能按实际导入边报告循环。CLI、REPL 和 LSP 提供各自的初始源码集合，共用加载流程。

检查器借用导入的接口，按名义身份索引直接导入的模块。每条重新导出声明沿其解析出的模块身份取得类型和可调用对象的证据。检查非限定名冲突时按名字查索引，诊断仍按导入顺序报告。

增量检查在源码文本和文件编号一致时复用解析语法。每次加载解析当前导入绑定，再组合可见的传递接口指纹。如果编辑未改变依赖接口，导入方可以复用上次的检查结果。编辑器为最近四个程序快照各保留一份编译器缓存。同一文件中的文档测试共享包根和已检查的导入，每个片段仍作为独立模块编译。

依赖解析器为待处理的依赖维护一个可回滚的优先队列。选定或移除版本时，只更新受影响包的依赖要求。解析器为选中的要求构造候选版本列表，并限制保留的冲突细节数量。

```text
按依赖排序的模块图
    → 声明：量纲、单位和类型
    → 签名：名称与前向引用
    → 函数体：类型、行、形状、效果与量纲约束
    → 默认化与泛化 → 导出接口与类型证据
                        │               │
                   供依赖者导入      降低检查后的代码
```

函数证据记录泛型参数确定后才能执行的约束。类型类操作保留字典选择，RSSN 调用可记录稳定的重载键。检查后的类型携带张量形状和量纲，动态下标和宿主接口另外执行边界检查。不同模块即使声明相同字段，名义构造器仍保留各自的声明身份。

张量尺寸求解器按尚未确定的变量为延迟方程建立索引。变量绑定后，按原顺序重试受影响的方程。发现延迟冲突时，诊断指出实际不相容的方程。

## 值、调度和效果

降低阶段构造基于槽位的 IR，显式保留绑定和闭包捕获。尾调用经跳板替换当前调用。参数较多且当前栈帧即将释放时，求值器先记录每个局部值最后一次作为参数出现的位置，再移动这些值。紧凑栈帧复用槽位缓冲区。参数只涉及少量槽位时，索引大小随参数数目增长。IR 与类型化 AST 解释器共用算术、IO、模式和内核操作。程序构造 IO 动作，由宿主在执行边界运行。源码插件和可移植任务继承调用方权限。可变宿主对象和内核句柄绑定到本会话及线程。

传播布尔常量时，各条件分支复用进入分支前的槽位事实，并在处理下一分支前撤销该分支的写入。优化器跳过静态不可达的分支和短路操作数。

常规值图使用线程局部引用计数对象，因此并行执行以解释器副本为单位。命令行和库运行入口与副本共享同一份不可变的已检查程序。工作线程初始化各自的作用域，并用相同代码身份、捕获值和支持的证据恢复可传输的闭包。映射保留输入顺序，归约使用固定分块。不可传输的计算可以走常规解释路径。可选 JIT 只编译符合条件的标量函数，守卫根据闭包身份与词法绑定判断已缓存的机器码是否适用。

## 工具链入口

| 工作 | 源码 |
|---|---|
| 加载入口、工作区或缓冲区覆盖 | `aevia-core/src/driver.rs` |
| 导出、证据与约束传播 | `aevia-types/src/check.rs`、`infer.rs`、`check/` |
| 降低、优化与执行 | `aevia-ir/src/lower.rs`、`optimize.rs`、`aevia-core/src/eval_ir.rs` |
| 补全、重命名、诊断及位置映射 | `aevia-analysis/src` 和 `aevia-lsp/src/server.rs` |
| 断点、单步与异常信息 | `aevia-core/src/debugger.rs` 和 `aevia-cli/src/debugger.rs` |

编辑器按协议要求映射位置并跟踪未保存文本。格式化与文档提取读取语法树，调试器读取正在执行的栈帧和区间。运行和测试命令针对保存后的源码，避免误用旧缓冲区。 [调试教程](/book/14-diagnostics-and-debugging?lang=zh)

重复查询复用程序快照中的文档大纲、语义标记和源码索引。客户端可以请求整篇文档或指定可见范围的语义标记。光标查询在首次用到模块的名称位置、词法作用域或已检查的表达式时建立相应索引。大纲和导航共用模块的行号索引来计算范围。格式化直接解析当前缓冲区，跳过导入加载和类型检查。文档内的同符号高亮与引用查询共用声明身份，只返回当前缓冲区中的出现位置。加载器观察到输入变更后，新快照会建立自己的索引。
