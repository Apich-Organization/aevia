# Aevia 与 RSSN 系统架构

Aevia 是检查量纲的科学计算语言。RSSN 为它提供符号和数值引擎，同时也提供独立的 Rust 和 C API。平台分发工具链，索引已签名的包，并提供规范、库参考和手册。

| 边界 | 输入 | 输出 |
|---|---|---|
| Aevia 前端 | UTF-8 源码与解析后的导入 | 已定型模块、量纲证据与诊断 |
| Aevia 运行时 | 已检查模块、参数与执行选项 | 值、IO 效果和诊断 |
| RSSN 内核 | 项或类型化值、算子签名与配置 | 约简项、数值与结构化结果 |
| 注册表 | 已验证的发布包及元数据 | 版本化归档、索引、透明日志与生成文档 |
| 教程执行服务 | 简短的独立程序 | 有上限的输出、错误与退出状态 |

## 仓库与依赖结构

从源码构建时两个项目位于相邻目录。语言 Cargo 工作区包含编译器、工具和适配器。平台使用独立 Cargo 工作区和锁文件，引用语言中的解析、包解析和文档工具。发布包时生成文档用的是语言自身的解析器，因此生产注册表可以生成文档而不链接数值引擎。

RSSN 管理算子标识和科学元数据。Aevia 定义语法、语言类型与运行行为。平台负责包协议和部署协议。新增 RSSN 算子通常只需类型或明确的动态边界，不需要修改语言解析器。
