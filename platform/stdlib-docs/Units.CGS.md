# `Units.CGS`

Source: `stdlib/Units/CGS.aev`

Use these centimetre–gram–second units with the same dimension checking as SI.

厘米–克–秒制单位与 SI 单位遵循相同的量纲检查。

The coherent SI value is the magnitude times the scale, plus the offset.

SI 相干单位下的值等于读数乘比例，再加偏置。
