# Aevia for VS Code

Syntax highlighting and the `aevia-lsp` language server for [Aevia](https://github.com/Apich-Organization/aevia) (`.aev`).

Put `aevia-lsp` and `aevia` on `PATH`, or set `aevia.server.path` / `aevia.cli.path`.

## Features

- **Hover, diagnostics, completion, formatting, semantic tokens** via `aevia-lsp`.
- **Run / Test current `.aev` file**:
  - `Aevia: Run Current File` (`aevia.runFile`) — `Ctrl+Alt+R` (`Cmd+Alt+R` on macOS) or the editor title bar ▶ button.
  - `Aevia: Test Current File` (`aevia.testFile`) — `Ctrl+Alt+T` (`Cmd+Alt+T` on macOS) or the editor title bar beaker button.
