# Aevia for Sublime Text / Aevia 的 Sublime Text 支持

Copy the `Aevia` directory to `Packages`, which you can open from
**Preferences → Browse Packages**. The syntax highlights ordinary, raw and
triple-quoted strings, including escapes and nested interpolation. Unclosed
ordinary or raw string text ends at the line break. Interpolation can span lines.

通过 **Preferences → Browse Packages** 打开 `Packages`，将 `Aevia` 目录复制
进去。语法高亮支持普通、原始和三引号字符串、转义以及嵌套插值。未闭合的普通
或原始字符串文本到换行处结束。插值表达式可以跨行。

Open `syntax_test_aevia_strings.aev` from the installed package and choose
**Tools → Build With → Syntax Tests** to run the highlighting checks.

打开已安装包中的 `syntax_test_aevia_strings.aev`，选择
**Tools → Build With → Syntax Tests** 运行高亮测试。
